# Roadmap

The roadmap is evidence-gated. A feature enters the core after real adoption demonstrates the need.

## v0.1 — executable methodology

- Interactive Architect preparation.
- Governed artifact templates.
- Specification and approval validation.
- Fresh-session Bash runner.
- Independent verification preparation.
- Greenfield and brownfield examples.
- Hermetic fixture lifecycle.

## Candidate next work

- More real-project transfer studies and sanitized case studies.
- A project-update command with explicit compatibility/version handling.
- Richer JSON Schema validation without adding fragile runtime dependencies.
- Signed/attested evidence manifests.
- Optional container execution profile for high-risk brownfield work.
- More provider adapters tested against their actual CLI contracts.
- Parallel execution only for mechanically independent slices.
- A small status UI only if terminal/status files prove insufficient.

## Explicitly not promised yet

- Fully autonomous product architecture.
- Automatic live deployment or provider spending.
- A universal cloud agent platform.
- Model-quality guarantees.
- An orchestration DSL for every development style.

The first priority is proving that another person can reproduce the method from this repository.
